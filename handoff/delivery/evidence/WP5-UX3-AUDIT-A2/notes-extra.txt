3. The stylesheet-wide hover scan (tests/e2e/hover.spec.ts:577-624)
   - Reads document.styleSheets of the signed-in Timesheet page (one CSS file; the lazy chunks carry no CSS), descends into media
     and grouping rules (container, supports, layer), fails on any style rule whose selector contains :hover outside a media rule
     whose text matches /hover:\s*hover/; empty allowlist with a stated rule for entries.
   - Not vacuous: it also requires more than 20 gated rules, five named needles, the lifted tint and the day tint.
   - Limits: the gate test is textual. A rule under "(hover: hover), (pointer: coarse)", "not all and (hover: hover)" or
     "(any-hover: hover)" counts as gated although it can apply on a touch screen (mutant M6b); a rule nested with CSS nesting inside a
     style rule is not visited (the stylesheet uses no nesting today). Risk, not a defect of the target.

4. surviveStall (tests/e2e/theme.spec.ts:77-86, used at :443-482)
   - Retries a wrapped measurement at most twice more when the error message matches /Timeout \d+ms exceeded|is settled/, rethrows
     anything else at once and after the third try. The wrapped measurements are contrast.ts settledStyle polls (message "the computed
     <property> is settled", call log "Timeout 7000ms exceeded while waiting on the predicate") and focusFromKeyboard's outer poll;
     toBeFocused fails with "Timed out ... waiting for expect(locator).toBeFocused()" and is not retried; Playwright actions have no
     action timeout in this config (a test-timeout error reads "Test timeout of 120000ms exceeded", which does not match). So in this
     test it retries only its own poll timeouts. Every wrapped call re-runs from the start (focusFromKeyboard re-focuses), so a retry
     is idempotent. Every assertion on the values is unchanged; the budget is 120 s.
   - A state that never settles still fails: it fails after three tries (about 3 x 7 s); a state that settles only after 7 to about
     21 s would now pass where it failed before (the test runs under reduced motion, where the product's transitions are 0.01 ms).

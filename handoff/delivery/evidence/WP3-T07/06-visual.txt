# Own visual check (not committed, not an acceptance harness: that is WP3-T14)
Synthetic manual and automatic revisions (Vietnamese name, a long holiday label, an incomplete open session,
OT only on both Sundays, a generated 420x90 PNG signature) were rendered by pdfjs-dist 6.4.299 to PNG at
scale 1.6 in a folder outside the repository (deleted afterwards). Checked by eye:
- US Letter portrait, one page; company header, title, submission and revision lines top right.
- Two WEEK blocks, each with Day, Date, Category, Time and OT (h:mm) rows and 7 columns; both Sundays present.
- Overtime Total 3:15 h:mm (2:15 + 1:00), hidden together with the OT rows when Show OT is off (test).
- Vietnamese diacritics render correctly in the name, header and holiday label.
- The long holiday label wraps in the Category cell, shrinks, ends with an ellipsis, and stays inside its column.
- The signature image sits above the signature line inside the 210x54 pt box; the typed name and the real sign
  date (10/07/2026, reporting zone) appear on the manual revision; manager signature and date stay blank.
- The automatic revision shows the amber "Employee review pending" banner, no signer name under the signature
  line and no sign date.
Also: the built module (dist/server/pdf/timesheetPdf.js, plain Node ESM) renders the same input to bytes
identical to the TypeScript source run (cmp equal), so pdf-lib and fontkit load under native ESM interop.

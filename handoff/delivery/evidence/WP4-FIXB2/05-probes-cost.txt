# WP4-FIXB2 05 parse cost of every probe package, before and after (in memory, one fresh child process per case)
#
# Budget (stated in src/server/import/xlsxReader.ts next to DEFAULT_READER_LIMITS): reading any package the reader accepts,
# or refuses after reading, takes at most 500 ms of event-loop time and adds at most 150 MiB of memory on this reference
# host (Node v24.21.0, Windows 11 x64 developer workstation). The stored report is at most 2 MiB (MAX_REPORT_BYTES).
#
# Commands: PROBE_ROOT=<task>/base PROBE_PKGS=<task>/pkgs node probes/cost.mjs [filter]   (before: source of 0f7fba2)
#           PROBE_ROOT=<task>/final2 PROBE_BUILD_ROOT=<task>/base PROBE_PKGS=<task>/pkgs node probes/cost.mjs   (after: final working tree)
#           node probes/summarize.mjs <after> <before>   ; all exit 0
# Packages are built once from the template by the test-support helpers and kept under <task>/pkgs (never the repository).
# 'preview ms' is the synchronous previewWorkbook call (reader + mapping) = event-loop time; '+N ms' is JSON.stringify of the
# preview model; maxRSS delta is the child's high-water mark after minus before. P1b/P7 are the first audit's packages (P6 used
# the two P1b <c/> packages over HTTP, see 06); r1/r3 are the recheck's; N* are new adversarial shapes of this fix.
# 'before' is the baseline 0f7fba2 (after WP4-FIXB); the first audit's own pre-FIXB numbers are in evidence/WP4-AUDIT-B.

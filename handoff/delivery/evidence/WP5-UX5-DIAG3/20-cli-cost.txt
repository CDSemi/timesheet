WP5-UX5-DIAG3 Q2a: what one spawned CLI costs (idle host, Node 24.21.0, scratch export of 5b8b718 plus the five uncommitted files; the Dropbox repository for the "repo" rows)

The "about 3.6 s per CLI" figure is a misreading of DIAG2: 30-C-econnreset.txt says drainJobsFrom (SIX sequential spawnSync of run-jobs) blocked the runner for 3594 ms on an idle host, i.e. 0.6 s per CLI. One CLI is 0.25-0.7 s idle (rows below). It reaches 3 s and more only when the host is loaded (smoke run under load: 3 CLIs blocked 39 s, see 40-smoke.txt).

No first-run penalty (antivirus scan of a new file) showed in repeated runs; Defender real-time protection is on and its exclusions need administrator rights to read, so antivirus cost is not isolated.

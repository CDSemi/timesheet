usage: validate_package.py [-h] [--preflight]

Read-only documentation checks, not application acceptance. Python 3.9+ and an
installed IANA zone database are required (on Windows: pip install tzdata).
--preflight checks the current repository; normal mode also compares the
historical r1.1 manifests.

options:
  -h, --help   show this help message and exit
  --preflight

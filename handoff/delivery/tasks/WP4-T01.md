## Required changes

1. **Production configuration.**
   - Production requires an explicit absolute `DATA_DIR` and an explicit absolute
     `DATABASE_PATH`. Refuse to start with a clear error otherwise.
   - Document `HOST` for containers: `0.0.0.0` only inside the container network. The
     development default stays `127.0.0.1`.
2. **Trusted proxy (O2).** Add `TRUSTED_PROXY_ADDRESSES`, an exact list with a default of
   none. Put the logic in a new `src/server/http/clientAddress.ts`.
   - Use the right-most untrusted `X-Forwarded-For` hop as the client address for the
     login limiter, but only when the socket peer is in that list.
   - Otherwise ignore every forwarded header.
   - Never trust client-supplied headers by default.
3. **Readiness.**
   - `/api/health` stays a liveness check.
   - Add `/api/ready`. It returns only booleans and integers in the style of
     `{status, schema:{expected, actual}, data_dir_writable}`: no paths, names or counts
     of people.
   - It returns 503 when the schema is not at the expected version or the data directory
     is not writable.
   - It needs no login. It reads nothing personal and writes nothing.
4. **`.env.example`** (new):
   - List every environment variable with a safe placeholder, capture mode as the
     default, and no secret value.
   - State that the application needs no session or signing secret (O3). Owner decision
     F-6 will align docs/07:9 later; do not edit docs in this task.
5. **Smoke.** `scripts/smoke-built-server.mjs` checks `/api/ready`, which must return
   200 with the allowlisted keys only.

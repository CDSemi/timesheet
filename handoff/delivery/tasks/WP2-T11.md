## Required content

- **OT screen** (OtScreen):
  - posted, provisional, reserved and available balances, from the server only;
  - negative-balance and reconciliation flags;
  - daily evidence;
  - record permission (E-7: a text reference until the WP3 file store) and reserve;
  - the E-5 insufficient-balance message;
  - leave list actions:
    - record use, partial use allowed. Under E-3 the action is explicit and idempotent,
      and is offered only on or after the leave date as the server reports it;
    - cancel and reverse, each sending `expected_version`.
  - the E-2 warning when a day's OT-kind leave minutes differ from the request's consumed
    minutes. The warning only informs; nothing is spent automatically.
- **History screen** (HistoryScreen): the caller's own history with before/after values
  and reasons, using the per-user cursor.
- **Evidence CSV download**: owner-only, through the existing route.
- **Navigation**: add OT and History entries to the shell.

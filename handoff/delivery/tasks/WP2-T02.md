## Required content (from the plan; binding)

- New migration `0002_ot_ledger.ts`; never edit a committed migration. It adds the tables
  `ot_ledger` and `ot_leave_requests`, append-only or versioned and protected by
  triggers.
- `ot_ledger` columns:
  - integer signed delta and type;
  - per-user unique source-event key;
  - opaque `source_ref` for future WP3 revision IDs;
  - self-FK `corrects_entry_id` and a leave-request FK;
  - work date, actor, reason and origin.
- `ot_leave_requests` columns: requested, approved, reserved, consumed, released and
  reversed minutes; leave date; permission fields; approval origin; version.
- Pure domain (`src/domain/ledger.ts`): posted = sum(deltas); available = posted −
  active reservations; correction delta = new − old.
- Internal services (`src/server/services/ledger.ts`, no HTTP route):
  - `postCredit`: a duplicate key returns the existing entry and never appends.
  - `postCorrection`: posts the difference linked to the original. A negative balance is
    kept and flagged for reconciliation (LG-08).
  - `postDeficitDebit`: when the available balance is insufficient, return a pending
    result with no silent overdraft (R-05).
  - `getBalance`.
- Covers: R-06; R-05 (debit outcome); FR-09; AC-03 (posting idempotency); LG-01, LG-02,
  LG-08, and the zero-delta part of LG-09.

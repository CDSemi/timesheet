## Required changes (binding)

1. **Owner-only PDF download** (server, `routes/submission.ts` through its T13A factory):
   `GET` a revision's ready PDF for its owner with `Cache-Control: no-store` and an
   attachment disposition with a sanitized filename; another user's revision 404,
   anonymous 401, not ready 409; never a static path.
2. **History and delivery UI** (`HistoryScreen.tsx`, `components/Delivery*.tsx`): the
   owner's revisions with origin and review state as the system records them (the
   employee's own screens say "review pending" for automatic submissions), PDF download,
   delivery attempts with state and redacted fault code, a reasoned correction entry
   point, an explicit resend, and the uncertain-delivery decision (mark delivered or
   resend) with a confirmation.
3. **Submission settings UI** (`SettingsScreen.tsx`, `components/Submission*.tsx`):
   recipients and templates with the server preview, the auto-submit switch with its
   effective rule, the automatic note line (enable switch and editable text, default
   "Automatic submission", one line, 1–120 characters) and the image option shown as the
   audited auto-image authorization ("Include my signature image on automatic
   submissions").
4. **Signature upload with consent** (`components/SignatureUpload.tsx`): upload a PNG/JPEG
   with a preview; per G-Q1 (b) the upload form shows "Use this image on automatic
   submissions" pre-selected; confirming performs the audited authorization (T07B:
   `POST /api/signatures?authorize_auto_image=true`, one transaction); unticking uploads
   without authorizing; after a new upload the UI offers to re-authorize with the new
   image. T07B returns 422 `submission_settings_required` when the user has no saved
   submission settings yet: the UI must handle this (for example, save the default
   settings version first with the user's explicit save, or show a clear step order),
   never silently drop the consent; cover it in a test.
5. **Grid status (T12 carry item)** (`TimesheetScreen.tsx`, `TimesheetGrid.tsx`): show the
   per-period review/delivery status from server fields in the grid area.
6. **UI standard:** token-only CSS (only `@media` conditions literal), the 4px radius
   token, the shared `--transition`, accessible labels and focus order, mobile-first at
   390×844 and 1280×800.

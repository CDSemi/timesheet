   1. Upload: one `.xlsx` with the exact content type, and a clear size limit.
   2. Preview table: each day with its source cell, label and flags. Unknown labels,
      duplicates, template defects and conflicts are visible.
   3. A per-day decision, limited to the actions the report allows; the default is
      skip.
   4. Commit with a confirmation step.
   - A second identical commit shows "already imported" (the replay).
   - Error codes map to clear messages: `workbook_rejected`, `decisions_required`,
     `decision_not_allowed`, `import_already_committed`, 413 and 415.

   edit controls are disabled, with a short reason matching 409 `imported_period`.
4. **Opening-balance form** (for example `src/client/components/OpeningBalanceForm.tsx`):
   - signed minutes, with hours and minutes input and an explicit sign;
   - the as-of date, the reason and the evidence reference;
   - a confirmation step showing the resulting balance;
   - a correction flow with a required reason.
   - Error messages follow the WP4-T10 codes.
5. **Pure models** in a new `src/client/importModel.ts`, unit-tested: decision rules,
   labels, error mapping and minute formatting.

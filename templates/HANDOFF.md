# Work-package handoff

Copy and complete with actual evidence. Keep matching .vi.md; machine logs need no translation.

- Package/scope, date and author:
- Actual model/effort/speed, or not observable:
- Baseline and resulting commit, or complete source archive:
- Implementation status; independent review status:
- Implemented behavior and changed files:
- Migrations/schema compatibility:
- Changed canonical contracts and reason, or none:
- Verification table: command | environment | exit status | observed result | evidence path:
- AC IDs covered; genuinely unrun/blocked paths:
- Synthetic screenshots/PDF/mail-capture evidence:
- Findings resolved, remaining defects and optional backlog:
- Owner setup inputs needed, excluding secrets:
- Production actions and explicit authorization, normally none:
- Usage/credits only if actually observable:
- One next action and matching prompt:

No “all passed” without execution evidence. Provider acceptance is not receipt; an automatic PDF is not employee sign-off.
